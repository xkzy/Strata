# Handoff: transparent runtime, virtual context, native CAS (2026-10-07)

Companion to `HANDOFF.md` (which describes the Go migration; see "Corrections" below). Everything here is **uncommitted**.
`CMakeLists.txt` also contains unrelated uncommitted work: stage only the hunks you own.

## What exists

### 1. Native CAS (`src/math/cas`, `include/strata/math/cas`) - clean-room port of Mathics behaviour
BigInt, exact Rational, Wolfram-style Expr, parser/printer, Expand/D/Simplify, factorization (Hensel/Zassenhaus), Solve
(refuses incomplete sets), Series, Limit, Integrate (verified by differentiation, definite integrals with pole checks),
matrices, combinatorics, **number theory** (PrimeQ, FactorInteger, Divisors, EulerPhi, PowerMod, ExtendedGCD, Fibonacci...),
**Range/Table/Sum/Product** (closed forms only where exact, otherwise unevaluated). Resource budgets and typed errors.
`src/math/mathics_backend.cpp` is the backend (name "StrataCAS"). GPL-3.0-or-later headers (derived from Mathics behaviour).
`FastNumericBackend` (int64) is overflow-checked; on any non-success `MathRuntime` re-runs on the CAS.
Test: `build/test_cas` (168 checks), `build/test_math_runtime`.

### 2. Transparent runtime (`src/rt`, `include/strata/rt`, library `strata_rt`)
`InferenceRuntime::generate(InferenceRequest, TextSink)`: messages in, text out. Internally: virtual-context paging, RAG,
memory, claim detection -> progressive verification (exact evidence / arithmetic CAS / number theory) -> recovery
(regenerate with hidden correction note, hedge, safe stop), loop detector + dynamic temperature (loops only), bounded
sentence-granular stream buffer, dependency/scope-aware verification cache. Not an MCP server; no tool the agent calls.
Test: `build/test_transparent_runtime` (11 scenarios, scripted mock generator).

### 3. Virtual context window (`virtual_context.{hpp,cpp}`)
Per-session logical context (tenant/user/workspace/agent/session). Content-addressed pages, BM25 index, dependency edges,
HOT/WARM/COLD/ARCHIVE tiers, pinning, spill to disk, byte-exact recovery, persistence across restarts, authorization before
retrieval, capacity from storage, honest `required_context_unavailable`, `model_info_json()` (physical vs virtual).
Persisted under `$STRATA_CONTEXT_DIR` or `~/.strata/contexts` (dirs 0700, files 0600). Test: `build/test_virtual_window`.

## Go server: real inference (why "the LLM always said Hello! I am Strata...")
Root causes, all fixed and verified against the real engine + model (`strata-coder-iq1_m.json`, RTX 4060):
1. The server never started the engine, and `engineipc` answered with **canned text** whenever the engine was not alive
   (any prompt containing "hi" -> the greeting). Removed: no engine / crashed engine / still loading now means HTTP 503 with the
   reason (`/health` shows `engine: starting|ready|failed` + `error`).
2. Prompts were tokenized with a **byte-per-id test tokenizer** and a naive ChatML string. New `pkg/tokenizer` (byte-level BPE,
   qwen35 pre-tokenizer, specials, streaming detokenizer) and `pkg/chattemplate` (the model's Jinja template, native). Both are
   tested against the Python reference / real Jinja: `go test ./pkg/tokenizer ./pkg/chattemplate` (472 + 308 oracle cases;
   fixtures regenerated by `tools/gen_tokenizer_fixture.py` / `tools/gen_chat_fixture.py` in a venv with `regex` + `jinja2`).
   The tokenizer tests need the pack's tokenizer dir (`STRATA_TOKENIZER_DIR`, default `~/Downloads/Strata-data/packs/coder-iq1_m/tokenizer`) and skip without it.
3. The engine command line (pack, shards, cache sizes, MTP ...) lives in `strata-<model>.json` (`exe`, `args`); the Go server
   ignored it. `bin/strata serve` now auto-detects the single `strata-*.json` with `args` in the working dir (or `--config`).
4. Protocol bugs: ids must be comma-separated, `DONE` fields are positional, a stopped request must be drained to `DONE`, one
   request at a time (all fixed in `pkg/engineipc`, tested with a fake engine process).
5. `/v1/chat/completions`, `/v1/messages`, `/v1/completions` were rewritten (`pkg/server/api_*.go`, `generate.go`, `outparse.go`):
   reasoning (`reasoning_content` / thinking blocks), tool calls (OpenAI + Anthropic), thinking switches (`reasoning_effort`,
   `enable_thinking`, Anthropic `thinking`), control tokens inside user text stay text, context overflow = 400.
   The old behaviour of **answering math/logic prompts with a computed "Result: ..." instead of calling the model** was removed (and its tests):
   verification belongs to the C++ transparent runtime, which checks the model's answer rather than replacing it.
6. HTTP `WriteTimeout` of 60 s cut long streams: now 0.
Not done: restart your running `bin/strata serve` (pid started before these fixes) after `go build -o bin/strata ./cmd/strata`;
the C++ `strata_rt` runtime (verification / virtual context) is still not connected to this server; no image input; one
engine session (requests are serialized); `STRATA_DEBUG_PROMPT=1` prints each rendered prompt for debugging.

## Gotchas
- `assert` is a no-op under `-DNDEBUG`; never put side effects inside it.
- Expr constructor `app(...)` (not `apply`): `apply` collides with `std::apply` via ADL.
- Security reviews fixed: verification cache key includes scope; state versions content-addressed; storage perms.
- Don't commit others' WIP (`fast_attention.hpp`, installers, `serve/` deletions). Ask before committing.
